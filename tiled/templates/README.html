MVTK Tiled Templates Reference

Generated from the 57 live tiled/templates/**/*.tx files. Each table mirrors the Tiled Properties panel and adds a Comments column.

New to Tiled or Defold? Start with the complete creator guide; use this page when you need every property and default.

Identity selectors and required IDs stay at the top level; related tuning is collected into one-level collapsible groups. Existing maps with flat overrides remain compatible. Newly placed templates already include the grouped properties; no upgrade step is needed.

Linked enemy art

Enemy art can be linked with the optional art file property. Select a numbered frame such as enemies/ghost_enemy/idle_01.png outside the Defold project, then Export Current Room. Export copies the skin folder and Prepare & Check syncs it. A deliberate enemy_type keeps its stats and behaviour while the linked skin supplies the art. Blank art keeps today's preset or directly supplied skin workflow.

Lights, anchors and blocks

Set the room map darkness float to 0–0.9; absent values use game_config.visual.default_room_darkness. Environment ▸ Light Source adds a radius/intensity-controlled light. Interaction ▸ Torch (torch_holder) switches a light with Interact: choose starts_lit, require_interact and allow_extinguish, optional labels, sound IDs and set_flag. Paint visible torch art in Tiled. Empty IDs use the placed object.

Navigation ▸ Grapple Point is a small static grapple target without script overrides. Tune the player hook in Project ▸ Game Settings… ▸ Grapple and mark the target with visible anchor art. See the Grappling guide for surfaces, exact shapes and obstruction rules.

Physics ▸ Pushable Block uses a resizable rectangle and captured Tiled art. Walk into it to push, or hold Interact beside it and move to grab and pull. move_embedded_tiles moves that art with the block; mass is emitted into the collision component and gravity_scale controls movement. Set a pressure plate’s allow_world to true to let the block hold it down.

All four templates belong on the top-level templates object layer and bake into editable gameobjects in the room collection.
