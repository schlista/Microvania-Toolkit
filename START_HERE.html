Microvania Toolkit — Start Here

Do these steps in order. Each step is one thing to do. The picture under a step shows what you should see, with a red box around what to click. The pictures come from Windows; on macOS and Linux the folder windows look different, but Defold and Tiled have the same menus and buttons.

Where everything goes

Three folders sit side by side in one folder for your game:

MyGame                    a folder for your game (any name)
├─ Microvania_Toolkit     the toolkit: game.project, MVTK.tiled-project, this guide
├─ Tiled Worlds           your own Tiled worlds and rooms
└─ MVTK_Sample_Worlds_…   the sample worlds, if you download them

Never put Tiled Worlds or a sample world inside Microvania_Toolkit. Tiled exports copies into the toolkit; your editable maps stay outside it.

Set up the toolkit

Get the tools and the toolkit

  1. 1

    Install Defold 1.14.0: https://github.com/defold/defold/releases/tag/1.14.0 Later 1.14.x updates are fine.

  2. 2

    Install Tiled 1.12.2: https://github.com/mapeditor/tiled/releases/tag/v1.12.2

  3. 3

    Download the toolkit ZIP (Microvania_Toolkit_<version>.zip) from https://github.com/schlista/Microvania-Toolkit/releases if you haven't yet.

Put the folders in place

  1. 4

    Make a folder for your game, for example C:\MyGame on Windows, or a folder named MyGame in your home folder on macOS or Linux. These steps call it MyGame.

  2. 5

    Inside MyGame, make a folder named Tiled Worlds. Your own maps go there.

  3. 6

    Move the toolkit ZIP you downloaded into MyGame. (Already unzipped it? Move that folder into MyGame instead, rename it Microvania_Toolkit and go on at step 9.)

  4. 7

    Right-click the ZIP and choose Extract All... (macOS and Linux: double-click the ZIP, or right-click it and choose Extract Here.)

  5. 8

    Make the box say C:\MyGame\Microvania_Toolkit and click Extract. (macOS and Linux: rename the unzipped folder to Microvania_Toolkit.)

  6. 9

    Check: MyGame holds Microvania_Toolkit and Tiled Worlds. You can delete the ZIP.

  7. 10

    Check: Microvania_Toolkit holds game.project, MVTK.tiled-project and this START_HERE.

Set up Defold

  1. 11

    Open Defold.

  2. 12

    Click Open From Disk...

  3. 13

    Open MyGame, then Microvania_Toolkit. Click game.project and click Open.

  4. 14

    Wait until the bottom-left corner of Defold says Ready. The first time takes a minute or two.

  5. 15

    Choose Project ▸ Set Up This Toolkit.

  6. 16

    Click Choose Maps Folder... If a folder was chosen before, the button says Change Maps Folder...: click that instead.

  7. 17

    In the folder window, click the Tiled Worlds folder once and click Select Folder.

  8. 18

    Click Close on the Toolkit Set Up message.

Set up Tiled

  1. 19

    Open Tiled.

  2. 20

    Choose Edit ▸ Preferences... (on macOS it is in the Tiled menu).

  3. 21

    Click the Plugins tab.

  4. 22

    Tick defold and lua. Tiled lists them by file name: defold.dll and lua.dll on Windows, libdefold.so and liblua.so on Linux. Leave boxes that are already ticked as they are; defoldcollection is not needed.

  5. 23

    Click Close.

  6. 24

    Choose File ▸ Open File or Project...

  7. 25

    In the Open File window, open MyGame, then Microvania_Toolkit. At the bottom right, set the file type list to Tiled Projects (*.tiled-project).

  8. 26

    Click MVTK.tiled-project and click Open.

  9. 27

    If a yellow bar says the project contains scripted extensions, click Enable Extensions. The Project panel lists Tiled Worlds.

  10. 28

    Check: the File menu ends with Export Current Room, Export All Maps and Tiled World, new_room_blank and Start a New World...

The toolkit is ready. Next, do one of these.

Try a sample world

  1. Download the sample worlds ZIP from https://github.com/schlista/Microvania-Toolkit/releases
  2. Unzip it into MyGame, next to Microvania_Toolkit. Never inside it. On Windows, choose Extract All..., click Browse..., pick MyGame and click Extract, so you don't get a folder inside a folder of the same name.
  3. Open one world's START_HERE.txt and start at its step 7.

Each sample world replaces some of the toolkit's settings and art. For a second world, unzip a fresh toolkit.

These pictures show the Saltspray Cove sample world. Every sample world has the same steps, and its own START_HERE.txt numbers them with its folder and file names; some worlds add a few (for example the Spine add-on). Do the toolkit steps above first.

Unzip the sample worlds next to the toolkit

  1. S1

    Move the sample worlds ZIP into MyGame. Right-click it and choose Extract All...

  2. S2

    Click Browse... Extracting straight away would put the folder inside a second folder with the same name.

  3. S3

    Click Local Disk (C:), click MyGame once and click Select Folder.

  4. S4

    Check that the box says C:\MyGame and click Extract.

  5. S5

    Check: the sample's folder sits in MyGame, next to Microvania_Toolkit, never inside it.

  6. S6

    Open the sample's folder. 1_Tiled_Originals holds its Tiled world, 2_Copy_Into_Toolkit its Defold files, and START_HERE.txt its own steps.

Copy the sample's Defold files into the toolkit

  1. S7

    Close Defold.

  2. S8

    Open 2_Copy_Into_Toolkit. Right-click the developer folder and click Copy (or click it once and press Ctrl+C).

  3. S9

    Open MyGame, then Microvania_Toolkit, and click Paste at the top (or press Ctrl+V).

  4. S10

    Click Replace the files in the destination. (macOS and Linux: copy the folder as the sample's README.html step 1 says; Finder's Replace would delete the toolkit's own files.)

Point the toolkit at the sample's maps

  1. S11

    Open Defold. Click the Microvania_Toolkit project in the list and click Open Selected.

  2. S12

    Choose Project ▸ Set Up This Toolkit and click Change Maps Folder...

  3. S13

    Open MyGame, then the sample's folder. Click 1_Tiled_Originals once and click Select Folder.

  4. S14

    Click Close.

  5. S15

    Choose Project ▸ Reload Editor Scripts.

Export the world from Tiled

  1. S16

    In Tiled, open MVTK.tiled-project again as in steps 24 to 27, so the Project panel shows the sample's folder.

  2. S17

    Choose File ▸ Open File or Project... Open the sample's folder, then 1_Tiled_Originals, then the world's folder. Set the file type list to World files (*.world).

  3. S18

    Click the .world file and click Open.

  4. S19

    The world's rooms appear in the Project panel, and its first room opens.

  5. S20

    Choose File ▸ Export All Maps and Tiled World.

  6. S21

    If Tiled says the project tile dimensions will change, click OK.

  7. S22

    When the message starts with "Exported", click OK.

Prepare and play in Defold

  1. S23

    In Defold, choose Project ▸ Game Settings...

  2. S24

    Click the Player art tab.

  3. S25

    Scroll down and click Import and preview...

  4. S26

    Click Use this art.

  5. S27

    Click Save and Prepare & Check.

  6. S28

    Click Continue.

  7. S29

    Click Use Tiled World Layout.

  8. S30

    Click Continue each time it asks again. This can take a few minutes.

  9. S31

    When the window says Preparation complete, click Close.

  10. S32

    Click Close in the Game Settings window.

  11. S33

    Choose Project ▸ Build. The game opens on its title screen.

  12. S34

    Click Play Game.

  13. S35

    Click an empty save slot.

  14. S36

    You're playing.

Make your own game

  1. Open docs/CREATOR_WORKFLOW.html in a web browser.
  2. Follow its section "Start here — make three rooms, then play".

Nothing is playable until your rooms are painted in Tiled, exported and prepared.

To tune movement, starting abilities, player art or an ending, stop the game and choose Project > Game Settings... in Defold. Click Save and Prepare & Check, finish its prompts, then choose Project > Build to play with the saved settings. The title screen has Play Game and Layout Editor. Player preferences are in Settings in the game's pause menu.

If something goes wrong

  • Tiled's File menu has none of the toolkit's commands: repeat steps 24 to 27.
  • Export says "Required exporters not found": repeat steps 20 to 23, then export again.
  • Tiled's Open File window doesn't list MVTK.tiled-project: set the file type list at the bottom right to Tiled Projects (*.tiled-project).
  • Set Up says to choose another folder: click Choose Again... and pick the Tiled Worlds folder from step 5. It must be outside the Microvania_Toolkit folder.
  • Anything else: see the troubleshooting section of docs/CREATOR_WORKFLOW.html, or open an issue at https://github.com/schlista/Microvania-Toolkit/issues

About this toolkit

Windows is the verified beta platform. macOS and Linux use the same steps but are experimental; the Creator Guide lists each platform's prerequisites.

This toolkit ships without example rooms or a ready-made campaign. WHERE_THINGS_ARE.txt (written by Set Up This Toolkit) lists this toolkit's paths.

Optional, only for rooms you open without MVTK.tiled-project: run tools\set_tiled_export_path.bat (Windows) or sh tools/set_tiled_export_path.sh (macOS/Linux) from the Microvania_Toolkit folder to install the Tiled commands into Tiled itself.
